# Submission checklist

1. Read the six-page Capstone_Report.pdf. The DOCX is supplied for any final personal edits.
2. Extract this package and upload its files and sample_inputs folder to the root of the Agentic_AI branch at https://github.com/layal-z/AAI614_Zeineddine/tree/Agentic_AI . Do not upload your API key or local recruitment_case_gpt.json.
3. Use Multi_Agent_Recruitment_System_GPT_v11.ipynb, the final notebook already uploaded to GitHub. The package includes this final v11 file downloaded from your commit.
4. Confirm that README.md, requirements.txt, recruitment_mcp_server.py and the notebook are visible in the branch. Open README.md to check the installation instructions.
5. Submit the PDF and the repository branch link through the course submission portal. Include the editable report only if requested.
6. Reviewers need their own funded OpenAI API access to generate new outputs. Saved notebook outputs can be inspected without an API key.

The optional Streamlit app is included under recruitment_app. Its eight offline tests pass; the imported-case mismatch was confirmed as a repeated approval timestamp with unchanged content.
